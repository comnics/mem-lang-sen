# M4 복습·일정

## 사용자 흐름

1. `/onboarding` 또는 `/settings`에서 시간대, 시작일, 학습 시간, 하루 시간 예산을 정합니다.
2. 요일별 반복 또는 기준일로부터 N일마다 반복을 선택합니다. 특정 날짜의 학습 추가/휴식 예외가 기본 반복보다 우선합니다. 시작일 전에는 배정하지 않습니다.
3. 등록한 발행 세트에서 `/today`가 복습을 먼저, 남은 시간에 새 문장을 배정합니다. 입력 회상과 말하기 자기확인은 별도 대기열입니다.
4. 제출 결과에 따라 다음 복습 기한을 저장합니다. 내 문장에서 다음 기한과 지연 입력 성공 기록을 확인합니다.
5. 전체 자동 학습 또는 세트별 자동 배정을 잠시 멈출 수 있습니다. 세트가 겹치는 문장은 다른 활성 세트가 있으면 계속 배정됩니다. 자율 세트 연습은 별도로 가능합니다.

목표일은 계획을 위한 표시이며, 목표일 도달로 완료 판정하거나 이후 복습을 중단하지 않습니다. 정해 둔 시간은 학습 대기열이 열리는 시각이며 푸시 알림을 뜻하지 않습니다.

## 복습 정책 relative-v1

순수 함수 `src/domain/review.ts`가 DB나 현재 시각을 직접 참조하지 않고 주어진 상태/시각/결과로 다음 상태를 계산합니다.

- 처음 무도움 정답: 단계 0, 1일 후 복습. 최초 학습을 지연 검증으로 세지 않습니다.
- 이후 유효 입력 회상: 직전 정책상 기한에 도달했고, 마지막 관련 노출로부터 24시간 이상 지난 첫 무힌트 정답일 때 단계가 올라갑니다.
- 단계별 간격은 **1 → 3 → 7 → 14 → 30일**, 직전 유효 회상부터의 상대 간격입니다. 30일 이후에도 30일 간격을 유지합니다.
- ‘정답이어도 어려웠어요’를 선택한 유효 정답은 같은 단계 간격을 유지합니다.
- 오답/도움 후 답은 단계 0, 1일 후로 재시작합니다. 과거 이력과 기존 지연 성공 기록을 삭제하지 않습니다.
- 이른 자율 연습이나 최근 노출 후 정답은 단계를 올리지 않습니다. 미래 기한은 유지하고, 이미 지난 기한이면 1일 후 다시 확인합니다.
- 말하기 GOOD/AGAIN은 독립된 자기확인 일정입니다. 입력 검증 횟수나 입력 단계를 올리지 않습니다.

힌트·정답 공개 및 제출 후 피드백은 사용자×문장 단위의 최신 노출 시각에 반영합니다. 세트/학습 방식이 달라도 이 노출 시각을 공유합니다. 동일 답안 이벤트 재전송은 기존 결과를 반환하며 학습 상태를 중복 갱신하지 않습니다.

이 정책은 설명 가능한 초기 제품 규칙입니다. 간격의 최적성, 장기 암기 완료, 발음 정확도, M5의 7/30일 유지 평가를 의미하지 않습니다.

## 기억 기한과 달력 배정

`src/domain/scheduling.ts`는 IANA 시간대와 로컬 달력일을 사용합니다. N일 반복은 UTC 24시간 나머지가 아니라 기준일의 로컬 날짜 차이로 계산합니다. DST로 없는 시각은 같은 날짜의 다음 유효 분으로 이동하고, 중복 시각은 하한 시각 이후 첫 시각을 선택합니다.

| 필드 | 의미 |
|---|---|
| `dueAt` | 복습 정책상 필요한 원래 UTC 기한 |
| `scheduledAt` | 해당 학습일의 실제 배정 창 UTC 시각 |
| `performedAt` | 서버가 접수·처리한 실제 제출 UTC 시각 |
| `studyDate`, `timezone` | 제출 당시 로컬 날짜와 시간대 스냅샷 |

예: 토요일에 기한이 도래해도 월·수·금 학습이면 월요일 학습 창으로 배정합니다. 원래 토요일 기한은 유지합니다. 시간대를 바꾸면 미래 배정만 다시 계산하며, 과거 제출의 날짜/시간대는 수정하지 않습니다. 세션 이력의 ‘시작일’은 세션 발급 당시 날짜로, 제출일과 다를 수 있습니다.

오늘 대기열은 요청 때 계산하므로 Cron이 없어도 동작합니다. 14일 미리보기는 현재 상태에서 배정되는 복습과 학습 가능일을 보여주며, 이후 성공/실패를 가정한 장기 예측은 아닙니다.

## 시간 예산과 복귀

초기 예상 소요시간은 복습 30초, 새 문장 60초입니다. 실제 측정 시간이 아닌 배정용 추정치이며, 오늘 제출한 문항과 발급했지만 아직 풀지 않은 자동 학습 문항을 입력/말하기 모두 합산합니다.

- 오래 밀린 기한부터 복습하고 남은 예산에만 새 문장을 넣습니다.
- 예산 밖 복습은 기한을 덮어쓰거나 완료 처리하지 않고 다음 학습 가능일에도 남깁니다.
- 7일 이상 제출 기록이 없다가 돌아오면 복귀일 전체 예산을 최대 3분으로 제한합니다. 첫 답안 후에도 그날의 복귀 예산을 유지합니다.
- 같은 날짜·방식의 자동 학습 시작을 동시에 요청하면 같은 진행 중 세션을 반환합니다. 두 방식 사이에도 미완료 문항 예산을 공유합니다.
- 일정 변경, 전체 정지, 세트 정지/해제 시 기존 자동 세션의 제출 기록을 보존하고 남은 배정을 다시 계산합니다.
- 날짜가 지났거나 시간대가 변경된 자동 세션은 새 답안·답 공개를 거절합니다. 발행 세트 등록이 없어지거나 문장이 숨겨지면 해당 문항도 학습할 수 없습니다. 유효하지 않은 남은 배정은 오늘 예산을 차지하지 않습니다. 이미 저장된 답안의 동일 재전송은 기존 결과를 반환합니다.

## 서버와 데이터

- `GET /api/v1/today?mode=WRITTEN|SPOKEN`: 서버 계산 대기열/날짜 미리보기.
- `POST /api/v1/today {mode}`: 서버 선택 문항으로 자동 세션 발급. 요청한 임의 문장 ID나 클라이언트 시각을 사용하지 않습니다.
- `GET/PUT /api/v1/study-plan`: 기본 정보, 일정 규칙, 날짜 예외 저장.
- `PATCH /api/v1/enrollments {setId,paused}`: 소유한 세트의 자동 배정 정지/복귀.
- 기존 answers API에 `hard`가 추가되고 응답에 `nextDueAt`, `reviewStep`, `qualified`, `reviewReason`이 추가됩니다.

Prisma migration `20261014010000_review_scheduling`은 기존 학습 기록을 보존합니다. 이전 상태는 단계 0, 마지막 연습+1일 기한으로 보수적으로 시작하고, 과거 정답/공개 기록에서 공유 노출 시각을 복구합니다. 이전 기록에 없던 당시 시간대나 지연 검증 성공은 추측해 채우지 않습니다.

M5의 주간/7일/30일 평가, 전체 달력·메모, M6의 푸시/Cron/PWA는 이번 구현 범위에 포함하지 않습니다.
