# M2 콘텐츠 운영

## 문장과 버전

문장에 한국어 회상 질문, 보조 뜻/상황, 대표 영어 문장, 허용 답안, 힌트, 설명, 레벨, 음원을 입력합니다. 허용 답안에는 대표 문장도 포함하세요. 대소문자·앞뒤 공백·일부 구두점의 표기 차이는 정규화하지만 단어 의미를 추측해서 정답 처리하지 않습니다. 문장 수정은 새 버전입니다. 이미 발행한 세트와 학습 이력은 이전 버전을 유지합니다.

MP3(`audio/mpeg`), WAV(`audio/wav`), OGG(`audio/ogg`), 최대 10 MiB. 업로드는 관리자 인가 후 서명된 경로로 수행하고, 서버가 업로드된 객체를 확인한 후에 연결합니다. 음원은 private bucket에 있습니다. 문항 최초 응답에는 정답과 음원 URL을 포함하지 않습니다. 정답 공개/채점 이후 짧은 만료 시간의 재생 주소가 발급됩니다.

## 세트

문장 버전을 순서대로 선택해서 초안을 만듭니다. 초안 → 검토 → 발행. 필수 내용과 준비된 음원이 없으면 발행되지 않습니다. 발행본 개정은 복제 후 새 초안으로 수행합니다. 보관한 세트는 새 학습 목록에서 제외하고 기존 이력은 유지합니다.

## CSV

UTF-8, 한 번에 1~100행. 대표 정답은 서버가 허용 답안에 자동 포함합니다. 필수 헤더:

```csv
prompt,meaning,target,acceptedAnswers,hint,explanation,level
다시 말씀해 주시겠어요?,상대에게 반복을 요청하는 상황,Could you say that again?,Could you say that again?|Could you repeat that?,Could you 로 시작해 보세요.,정중하게 다시 말해 달라고 요청하는 표현입니다.,A1
```

쉼표·줄바꿈을 포함한 값은 표준 CSV 큰따옴표로 감쌉니다. 허용 답안은 `|`로 구분합니다. 입력 전체를 먼저 검증하고 한 행이라도 오류가 있으면 확정 시 어떤 행도 저장하지 않습니다. 가져온 문장은 초안이며 음원을 연결하고 별도로 검토·발행해야 합니다. 관리자 화면의 미리보기는 서버 검증 결과를 표시합니다.

## 데모 자료

`fixtures/audio/seed-1.wav`–`seed-6.wav`는 해당 seed 영어 문장을 macOS Samantha 음성으로 생성한 로컬 시연 자료입니다. 합성음성을 사람이 녹음한 음성으로 표시하지 않습니다. 실제 서비스용 문장·허용 표현·난도·음원 이용 조건 검수는 별도 운영 작업입니다.

## 상황별 시드 확장

기존 2세트·6문장을 유지하고, 공통 표현 5세트(감사와 거절 분리), 여행 핵심 5세트, 가족 여행 4세트, 문제 해결 4세트, 일상 확장 5세트를 추가했습니다. 신규 세트는 각 6문장으로 총 23세트·138문장, 전체는 25세트·144문장입니다. [전체 신규 문장 목록](seed-catalog.md)을 참고하세요.

- 실행 진입점: `prisma/seed.ts`. 상황별 원문: `prisma/seed-data/conversation.ts`. 정답·힌트·설명·안정 ID 구성: `prisma/seed-data/catalog.ts`.
- `pnpm db:seed`는 로컬 Supabase에 음원과 발행 세트를 반영합니다. 동일 내용으로 재실행해도 문장·버전·세트가 중복되지 않습니다. 기존 사용자의 등록, 답안, 복습 상태를 수정하지 않습니다.
- 신규 시드 문장을 수정하면 새 문장 버전과 새 세트 개정본을 만듭니다. 과거 발행 세트·등록·평가 기준은 그대로 유지됩니다. 개정본으로 자동 등록을 전환하지 않습니다. 기존 문장 키/순서는 식별자이므로 재배열하지 말고, 문장을 더 넣을 때는 뒤에 추가하세요.
- `conversation-*.wav`는 대표 정답의 해시로 이름을 정한 macOS Samantha 합성 음원입니다. 정상 시드 실행은 저장된 WAV를 사용하므로 macOS가 아니어도 됩니다. 문장을 수정·추가한 경우 macOS에서 `pnpm seed:audio`로 새 음원을 생성한 뒤 함께 저장합니다.
- 아이가 아플 때·긴급 도움 세트는 증상 전달과 도움 요청을 위한 영어 회화입니다. 진단, 투약 지시, 국가별 긴급 번호는 포함하지 않습니다.
