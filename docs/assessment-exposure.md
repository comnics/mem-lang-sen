# 평가 전 힌트·정답 노출 정책

유지(7/30일)·주간(회상/응용) 평가는 도움 없는 첫 답안을 기록합니다.

- 사용자의 **현재 학습 계획 시간대의 같은 달력 날짜**에 HINT 또는 ANSWER 노출이 있는 문장은 그날 평가를 연기합니다. DAILY뿐 아니라 다른 세션·모드·문장 버전·응용 문항에서 본 같은 문장도 해당합니다.
- 새 평가 문항을 만들거나 문장 버전/형식을 바꾸어 노출 기록을 우회하지 않습니다. 노출 이력이 있는 문항 자체도 재사용하지 않습니다.
- 노출 없는 당일 WRITTEN DAILY/ASSESSMENT 미제출 문항은 기존대로 재사용하며, 이미 예약된 시간을 다시 예약하지 않습니다.
- 평가 생성과 제출은 reveal과 동일한 사용자 행 잠금 아래 노출을 확인합니다. 시작 후 다른 세션에서 노출한 경우 제출은 안내와 함께 409로 거절되며 답안/평가 결과를 쓰지 않습니다. 평가 화면에서 다시 시작해야 합니다.
- 오염된 문항과 정상 문항이 섞인 ASSESSMENT 세션은 재시작 시 미제출 배정을 해제하고 ABANDONED로 전환한 후 정상 문항만 다시 배정합니다. 기존 제출 결과는 유지하며, 폐기된 예약은 예산에서 제외합니다. DAILY 세션은 폐기하지 않고 오염된 문항의 미제출 평가 연결만 해제하여 일반 학습을 보존합니다. 이 처리는 세션 생성과 같은 트랜잭션이므로 실패 시 전체 롤백됩니다.
- 다음 학습일에는 새 평가 문항으로 다시 시도할 수 있습니다. 이는 **24시간 무노출 보장이나 장기 기억 검증을 의미하지 않습니다**. 학습일 경계에 인접한 노출은 간격이 짧을 수 있으며 기존 exposureGapHours 기록을 유지합니다.
- 배정 분모와 평가 창은 변경하지 않습니다. 연기 중에는 응시/정답/오답을 기록하지 않지만, 마감이 지나면 기존대로 미응시로 표시하고 늦은 응시는 기간 밖으로 집계합니다. 연기로 마감이 자동 연장되지 않습니다.
- 일반 학습의 ASSISTED 정책과 과거 평가 결과는 변경하지 않습니다. 과거 오염된 평가를 소급 교정하지 않습니다. 도움받은 답을 CORRECT로 바꾸지 않습니다.

평가 화면은 진행 가능한 노출 문장을 `DEFERRED`로 표시하고 당일 available 목록에서 제외하며 다음 학습일 재시작을 안내합니다. 제출 거절도 같은 정책 문구를 사용합니다.

조회는 ExposureEvent의 `(userId, createdAt)` 인덱스를 사용하도록 마이그레이션을 추가했습니다. 운영 적용 전 격리 PostgreSQL에서 마이그레이션·트랜잭션 롤백과 통합 회귀를 검증해야 합니다. 롤백은 코드 revert와 해당 인덱스 제거이며, 학습/평가 데이터 삭제는 필요하지 않습니다.
