# 개인 문장 기능 회의 결정·설계·WBS

> For Hermes: 구현은 subagent-driven-development로 진행하되 사용자 명시 지시에 따라 중간 테스트/빌드/린트/타입검사/구현 리뷰는 생략하고 모든 구현 후 최종 검증 단계에서 수행한다. 최종 결함 수정 후 재검증은 허용한다. 자동 병합·운영 배포 금지.

**Goal:** 사용자가 직접 입력하거나 XLSX/TXT에서 가져온 개인 문장을 편집하고 기존 학습·복습 흐름에서 학습한다.

**Architecture:** 기존 Sentence/SentenceVersion/StudySet/Enrollment를 확장하되 PUBLIC/PERSONAL scope와 owner로 격리한다. 불변 문장 버전·soft archive로 기존 이력을 보존하고 동일 학습 예산을 사용한다.

**Tech Stack:** Next.js/TypeScript/Prisma/PostgreSQL/Supabase Auth. 원문 파일을 영구 저장하지 않는 제한된 XLSX/TXT 파서.

## 회의 근거와 최신 기준
제품·UX/업로드 보안 제안과 코드 기반 아키텍처 제안을 부모가 종합했다. 세부 논의는 `/Users/jarvis/.hermes/review-teams/mem-lang-sen/design/personal-sentences/{source-architecture.md,product-security-proposals.md}` 참조. 초기 조사는695b385 기준이며 구현용 최신 clone은 **dad8eec0ac7055eb8a8a76ff2bd0520f60c6897c**이다. 그 사이 #12/#13/#17/#18이 병합됐으므로 auth·scheduling·records 변경을 보존한다. 이전 조사에서 PR 미병합으로 언급한 부분은 현재 구현의 선행 차단이 아니다.

## 채택·보류 결정
- 채택: 비공개 개인 세트, 직접 다중 입력, .xlsx/UTF-8 .txt 가져오기, 저장 전 행 편집·오류 표시·중복 수량, 저장 후 편집, 보관/복구, 학습 등록·자율 연습·오늘/복습 연결.
- 입력: 한국어 질문/상황(prompt)과 영어 정답(target) 필수. 설명/힌트/해설은 선택. 영어만 있는 TXT는 미리보기에서 질문을 채워 저장한다. 질문/뜻을 AI가 임의 생성하지 않는다.
- 파일: XLSX 헤더 prompt,target 및 선택 meaning,acceptedAnswers,hint,explanation,level. TXT는 한 줄 영어 또는 2/3열 TSV 모드를 명시 선택. 템플릿/예시 제공. XLS/XLSM/수식/외부 참조·손상 파일은 명확히 거절한다.
- 한도: 2MiB 파일, 100행/세트, 활성 개인문장 1,000개/사용자. ZIP 확장 총량16MiB·200entry, 스트림 실제 크기·압축해제 시간/셀 한도 강제. 별도 검증 없이 MIME/확장자만 신뢰하지 않는다.
- 접근: 타 사용자 및 관리자 공용 목록/조회/발행/clone/검색에 개인 콘텐츠 노출 금지. 서버 owner 검증, 기존 공용 품질 게이트 유지.
- 편집: 새 version 생성, 기존 학습 이력/채점/평가 baseline 보존. 내용 변경 시 기존 진도 자동 초기화 없음. 새 학습 주기가 필요하면 새 문장 추가. 활성 구버전 세션은 안전히 무효화하고 기존 event 재전송의 멱등 결과 보존.
- 작성 화면 정답 노출은 assessment exposure와 연결하되 GET 목록에 무조건 정답을 넣거나 GET 자체의 임의 mutation을 도입하지 않는다. 명시 authoring exposure 작업 또는 동등한 서버 계약 사용.
- 보관은 영구 삭제가 아니며 기존 기록 유지. 공유/협업/AI 번역/TTS/음원 업로드/다국어/태그/계정 병합 제외.
- 최초 저장과 학습 등록은 구분. 등록 후 기존 통합 일일 예산·복습 우선 규칙 적용. 무음원 학습 허용, 공용 발행 음원 요건 완화 금지.

## 구현 전달 상태 (실행 검증 전)

- W01–W13: schema/migration, 공용 격리, 개인 CRUD/학습/파서/import/API/UI, unit·DBintegration·E2E 테스트 및 문서 **작성**.
- W14: **미실시**. 개발 중 테스트/빌드/타입검사/브라우저/코드 리뷰 명령을 실행하지 않았다. 편집 도구의 자동 JSON 구문/LSP 알림은 최종 검증 증거가 아니다.
- 구현 상세·운영 제약: `docs/personal-sentences.md`. 실제 worker bundling, migration, 권한·학습·예산·모바일 및 보안 수용 기준은 부모의 격리 최종 캠페인에서 확인해야 한다. 작성 완료가 PASS/배포 준비 완료를 뜻하지 않는다.

## 최종 증거 기준
직접입력→수정→학습→진도/복습, XLSX/TXT 미리보기→오류수정→전량저장, 보관/복구, 중복/재전송/충돌, 두 계정 IDOR/공용누출, 기존 공용·평가·예산 회귀를 검증한다. 실제 PostgreSQL 및 브라우저 증거와 mock 단위를 구분한다. 비밀값을 전달하지 않는 격리 환경을 사용하며 준비가 안 되면 미검증을 성공으로 보고하지 않는다. 최종 PR은 별도 제출 검증 후 생성하며 병합·배포는 하지 않는다.
