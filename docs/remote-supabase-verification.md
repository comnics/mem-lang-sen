# 원격 Supabase 연결 검증

검증일: 2026-10-14. 로컬 앱 주소: http://127.0.0.1:3100

- 원격 Auth 관리자 API와 앱의 공개 키를 이용한 브라우저 로그인 성공.
- PostgreSQL: 관리자 및 제한된 `app_runtime` 연결, 인증서 검증을 포함한 TLS 1.3 확인. 마이그레이션 3개 적용.
- 콘텐츠: 발행된 세트 25개, 문장 144개, READY 음원 144개 반영.
- Storage: `sentence-audio` 비공개 버킷. 익명 공개 URL 접근 차단, 채점 후 서명 URL을 통한 음원 다운로드 성공.
- 임시 계정으로 모바일 브라우저 로그인/온보딩, 세트 등록, 입력 회상 3문장 채점, 같은 답안 재전송 중복 방지, 다음 복습일 저장, 학습 기록, 일반 사용자의 관리자 API 접근 차단 확인.
- 시드 재실행 후 문장·버전·세트·세트 구성·응용 문제의 행 수와 내용이 동일함을 확인. 음원 144개도 중복 생성되지 않음. 기존 기본 음원 6개의 업로드 완료 시각은 재실행 시 갱신되므로 전체 행 해시 동일성 검사는 해당 메타데이터 차이로 실패했으며, 콘텐츠 중복은 없었음.
- 테스트용 Auth 계정과 해당 앱 학습 기록은 검증 후 삭제.
- 원격 환경 변수를 반영한 프로덕션 빌드 및 로컬 서버 재시작 완료.

테스트하려면 위 주소에서 회원가입/로그인 후 세트를 선택한다. 기존 로컬 데모 계정은 원격으로 복사하지 않았다. 가입 확인 메일 전달과 비밀번호 재설정 메일, Vercel 배포, 푸시 전달은 이번 검증에 포함되지 않는다.

재실행 절차는 `docs/deployment.md`의 원격 콘텐츠 시드 절을 따른다. `.env.local`을 교체할 때 앱 전용 DB 계정과 TLS 설정을 유지한다. 이 컴퓨터의 CA 절대 경로를 Vercel 환경 변수에 그대로 복사하지 않는다.
